# ACI Standards Roadmap

This is a roadmap for the specification, not a product roadmap. It shows where the standard is headed and what milestones need to be met before advancing.

```
v0.9 — Draft
  │
  ├── Independent implementations (3+)
  ├── Community feedback incorporated
  └── Stable core validated
       │
       ▼
v1.0 — Stable
  │
  ├── Community RFCs begin
  ├── Reference test suite
  └── Certification framework
       │
       ▼
v1.x — Community Growth
  │
  ├── RFC-001: YAML support
  ├── RFC-002: Discovery improvements
  ├── RFC-003: Authentication declarations
  ├── RFC-004: Digital signatures
  └── RFC-005: Ontology alignment
       │
       ▼
v2.0 — Extensions
  │
  ├── Proven extension patterns
  ├── Domain-specific profiles
  └── Interoperability test suite
       │
       ▼
Future
  │
  ├── Formal certification program
  ├── Public registry of implementations
  └── Neutral governance transition
```

## Milestones

| Milestone | Condition | Status |
|-----------|-----------|--------|
| **v1.0 Promotion** | 3+ independent implementations, feedback incorporated, stable core | Pending |
| **Community RFCs** | v1.0 published | Pending |
| **Reference Test Suite** | v1.0 published | Pending |
| **Certification Program** | v1.0 published + market demand | Pending |
| **Neutral Governance** | Multiple contributors, shared stewardship | Pending |
